## 四梯队改进实施方案

**范围说明**：做全部四个梯队，但以下三项不做——①自定义分类/搜索（此前标注"次要"，等记账主功能稳定后再说）②喝什么菜单数据搬云端（无管理端前纯增维护成本）③云数据库索引（控制台才能建，我给你操作步骤）。每完成一个梯队提交一次并推送，共 4 个功能提交。

---

### 第一梯队：工程兜底

1. **记账分页（修数据丢失隐患）**
   - 云函数 `list` 加 `page` 参数：limit 50，返回 `{ list, hasMore }`
   - 前端 `processBills` 改为可累积模式，`onReachBottom` 加载下一页追加，切月重置
2. **深色模式收口**：`app.json` 开 `"darkmode": true` + `themeLocation`，新建 `theme.json`（导航栏保持品牌蓝，页面底/tabBar 底/文字色给深色值，图标不变——灰色描边在深色底上可读）
3. **意见反馈**：工具箱入口页列表底部加 `<button open-type="feedback">` 卡片（微信自带反馈通道，零配置）
4. **数据库索引**：HANDOVER.md 写清控制台操作步骤（accounts 建 `_openid+date`，habit_logs 建 `_openid+date`），标为待用户 2 分钟操作

### 第二梯队：记账做深

1. **编辑账单**：云函数加 `get`（单条）和 `update` action（含所有权校验，模式同 delete）；账单条目加 `bindtap` 点击进 add 页带 `?id=`，add.js 支持编辑模式（加载回填、保存走 update、标题改"编辑账单"）；长按删除保留
2. **月度预算**：新集合 `budgets`（`{_openid, month, amount}`，按需建表+独立 try-catch）；云函数加 `getBudget`/`setBudget`；记账首页汇总卡下方加预算进度条——已用 <80% 蓝 / 80~99% 橙 / ≥100% 红，点击弹出输入框设置金额（showModal editable）
3. **趋势图**：云函数加 `trend` action（一次范围查询近 6 个月，内存按月聚合）；stats 页顶部加"近 6 个月"柱状图——纯 view 自绘（无第三方图表库），高度按支出比例，当月高亮，配色走设计令牌天然支持深色
4. **数据导出**：stats 页加"导出本月 CSV"按钮，云函数 `export` action 返回当月全部账单，拼 CSV 后 `wx.setClipboardData`，提示"已复制，粘贴到电脑表格即可"

### 第三梯队：习惯闭环 + 增长

1. **首页第三张统计卡"连续打卡"**：`listHabits` 本来就返回每个习惯的 `streak`——首页 loadStats 已在调它，取最大值展示即可，**零额外请求**；点击跳习惯 Tab
2. **打卡震动反馈**：打卡成功时 `wx.vibrateShort`（鼓励条已存在，补上触觉）
3. **分享能力**：首页/记账/习惯/随机 4 子页/工具箱全部加 `onShareAppMessage` + `onShareTimeline`（标题按页面语境写）
4. **打卡海报**：习惯页头部加"海报"入口，canvas 2d 绘制（品牌蓝渐变底、今日完成 x/y、最高连续天数、近 7 日打卡格、日期落款），生成后 `wx.showShareImageMenu` 分享/保存
5. **日历页统计**：头部加"本月打卡 N 天 · 最长连续 M 天"（月内计算，不跨月查历史）

### 第四梯队：体验细节

1. **首页加"随机一下"功能卡**：现 3 卡在 2 列网格里是尴尬的 2+1，加第 4 张（紫色调，复用 cat-random 图标，跳 `/pages/random/index`）凑成 2×2
2. **骨架屏推广**：记账列表和习惯列表的"加载中..."文字换成 skeleton 组件（组件已存在，补注册+接线）
3. **首页统计数字滚动动效**：支出金额从 0 滚动到目标值（~600ms），打卡卡同步微动效

### 收尾

- HANDOVER/AGENTS 更新（budgets 集合、新 action 清单、索引操作步骤）
- 全部 JS 过 `node --check`；云函数改动用沙箱桩件跑用例（分页边界/预算增改/趋势聚合/CSV 数据完整性）
- 每梯队一个 commit 并推送

所有云调用带 `followSystem: true`；可选集合独立 try-catch；前端源码不用展开语法；不用双重 orderBy；新颜色同时给深色值。
