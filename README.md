# 生活小工具 · life-toolkit

> 微信原生小程序 + 微信云开发：记账 / 习惯打卡 / 随机工具 / 工具箱，一个人的生活瑞士刀。

个人业余项目，自用为主，仅供学习交流。设计走"圆角蓝图"风格：设计令牌集中在 `app.wxss`，图标系统见 `ICON-DESIGN.md`，深浅色模式全套支持。

## 功能一览

| 模块 | 能力 |
|---|---|
| 🏠 首页 | 仪表盘：实时天气（高德）、本月支出 / 今日打卡 / 最高连续统计卡（数字滚动动效）、功能入口 |
| 💰 记账 | 收支记录（点击可编辑）、月度预算三态进度条、分类占比、近 6 个月趋势图、本月账单 CSV 导出（剪贴板）、分页加载 |
| ✅ 习惯 | 打卡（震动反馈）、连续天数统计、打卡日历（本月最长连续）、canvas 生成打卡海报、长按编辑删除 |
| 🎲 随机 | 今天吃什么 / 喝什么（282 款 2026 在售饮品 + 附近品牌门店）、随机决策器、随机数、抽签分组 |
| 🧰 工具箱 | 视频压缩、视频截图、图片压缩、短视频去水印（抖音/皮皮虾/小红书，仅供学习备份） |

全部 12 个核心页面支持分享给好友 / 朋友圈。

## 技术架构

- **前端**：微信原生小程序（非 uni-app），无第三方 UI 库与图表库（趋势图为纯 view 自绘）
- **后端**：微信云开发——5 个云函数 + 云数据库 + 云存储，运行时 Node 8.9
- **云函数**：`login`（openid）/ `bookkeeping`（记账+预算+趋势+导出）/ `habit`（打卡+连续计算）/ `nearby`（高德周边搜索+逆地理+实况天气代理）/ `unwatermark`（短视频解析转存）
- **数据集合**：`accounts` / `habits` / `habit_logs`（按需自动建表）/ `budgets`（按需自动建表）
- **外部依赖**：高德地图 Web 服务（Key 走云函数环境变量 `AMAP_KEY`，代码内无密钥）

## 测试

云函数测试采用本地沙箱方式：`tests/stubs/wx-server-sdk.js` 内存桩件模拟数据库（主键唯一性与真实 MongoDB 一致），加载**真实云函数源码**做接口级验证，无需部署即可运行：

```bash
node tests/habit-checkin.test.js
```

当前覆盖 `habit` 的 `checkIn` 接口 6 项：并发双写防重（幂等 `_id`）、顺序重复打卡、旧随机 `_id` 历史数据兼容、查重超时 fail-closed、集合不存在自动建表、幂等键跨用户/跨日期隔离。

## 快速上手

1. 微信开发者工具导入本项目（AppID 换成自己的或用测试号）
2. 开通**云开发**，创建环境后把 `miniprogram/app.js` 里的环境 ID 改成自己的
3. 对 `cloudfunctions` 下 5 个云函数逐个**「上传并部署：云端安装依赖」**
4. 需要"附近品牌/天气"功能时：云开发控制台 → 云函数 `nearby` → 配置 → 环境变量，新增 `AMAP_KEY`（[高德开放平台](https://lbs.amap.com/)申请，Web 服务类型）
5. 建议在数据库控制台给 `accounts` 集合建组合索引（`_openid` 升序 + `date` 降序），`habit_logs` 同理
6. 编译预览。真机体验定位、保存相册等能力（模拟器不可靠）

详细部署注意事项与踩坑记录见 [HANDOVER.md](HANDOVER.md) 第八节「已知陷阱清单」。
